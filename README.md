# Quiz Master Pro

An advanced online coding quiz application rewritten in React and TypeScript with Vite.

## Features

- **10 Programming Languages**: C, Java, Python, JavaScript, C++, HTML, CSS, SQL, Dart, and TypeScript.
- **Topic-Focused Quizzes**: Over 50+ topics covering syntax, OOP, concurrency, DOM manipulation, queries, data types, and more.
- **Customizable Quiz Settings**: Choose question quantity (5, 10, 15, or 20 questions) and difficulty level (Mixed, Easy, Medium, Hard).
- **Interactive Quiz Engine**:
  - Live scoring and dynamic progress tracking
  - Keyboard shortcuts (`A`, `B`, `C`, `D` to choose options, `Enter` to advance)
  - Validation hints and responsive UI
- **Detailed Scorecard & Metrics**:
  - Accurate calculation of score, percentage, and star ratings
  - Stat breakdown of correct answers, wrong answers, and accuracy
- **Comprehensive Answer Review**:
  - Filter by All Questions, Correct Answers, or Wrong Answers
  - Direct comparison of your choice vs. correct answer
  - Detailed explanation provided for each question

## Getting Started

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
